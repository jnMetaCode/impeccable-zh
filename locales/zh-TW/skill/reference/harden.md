只能處理完美資料的設計不具備生產可用性。應針對真實使用者帶來的輸入、錯誤、語言和網路條件加固介面。

中文產品還應讀取 [chinese-ux-copy-cn.md](chinese-ux-copy-cn.md)，驗證動態中文文案、金額時間、權限和高風險確認狀態。

## 評估加固需求

識別弱點和邊界情況：

1. **使用極端輸入測試：**
   - 超長文字（姓名、描述、標題）
   - 超短文字（空值、單個字元）
   - 特殊字元（emoji、RTL 文字、重音字元）
   - 大數值（百萬、十億）
   - 大量專案（1,000+ 列表項、50+ 選項）
   - 無資料（空狀態）

2. **測試錯誤場景：**
   - 網路故障（離線、慢速、超時）
   - API 錯誤（400、401、403、404、500）
   - 校驗錯誤
   - 權限錯誤
   - 限流
   - 併發操作

3. **測試國際化：**
   - 較長翻譯文字（德語通常比英語長約 30%）
   - RTL 語言（阿拉伯語、希伯來語）
   - 字元集（中文、日文、韓文、emoji）
   - 日期和時間格式
   - 數字格式（1,000 與 1.000）
   - 貨幣符號

**關鍵要求：** 只能處理完美資料的設計不具備生產可用性。必須針對現實情況加固。

## 加固維度

系統性提高韌性。

### 文字溢位與換行

**長文字處理：**

```css
/* 單行省略 */
.truncate {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

/* 多行截斷 */
.line-clamp {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

/* 允許換行 */
.wrap {
  word-wrap: break-word;
  overflow-wrap: break-word;
  hyphens: auto;
}
```

**Flex/Grid 溢位：**

```css
/* 允許 flex 項縮小到內容寬度以下 */
.flex-item {
  min-width: 0;
  overflow: hidden;
}

/* 防止 grid 項溢位 */
.grid-item {
  min-width: 0;
  min-height: 0;
}
```

**回應式文字尺寸：**

- 使用 `clamp()` 實作流式字號；
- 設定可讀下限：行動版正文 16px，與排版指南一致；只有真正次要的文字才使用 14px。iOS Safari 會強制放大字號小於 16px 的聚焦輸入框，從而破壞表單佈局；
- 測試 200% 文字縮放；
- 確保容器能隨文字擴充功能。

### 國際化（i18n）

**文字擴張：**

- 為翻譯預留 30%～40% 空間；
- 使用能隨內容調整的 flexbox/grid；
- 使用較長語言測試；
- 文字容器避免固定寬度。

```jsx
// ❌ 錯誤：假設英文文字很短
<button className="w-24">Submit</button>

// ✅ 正確：根據內容擴張
<button className="px-4 py-2">Submit</button>
```

**RTL 支援：**

```css
/* 使用邏輯屬性 */
margin-inline-start: 1rem; /* 不使用 margin-left */
padding-inline: 1rem; /* 不使用 padding-left/right */
border-inline-end: 1px solid; /* 不使用 border-right */

/* 或使用 dir 屬性 */
[dir="rtl"] .arrow { transform: scaleX(-1); }
```

**字元集支援：**

- 所有環節使用 UTF-8；
- 使用中日韓 CJK 字元測試；
- 使用 emoji 測試，它們可能佔 2～4 個位元組；
- 處理拉丁、西里爾、阿拉伯等不同書寫系統。

**日期和時間格式：**

```javascript
// ✅ 使用 Intl API 正確格式化
new Intl.DateTimeFormat('en-US').format(date); // 1/15/2024
new Intl.DateTimeFormat('de-DE').format(date); // 15.1.2024

new Intl.NumberFormat('en-US', {
  style: 'currency',
  currency: 'USD'
}).format(1234.56); // $1,234.56
```

**複數：**

```javascript
// ❌ 錯誤：假設只存在英文複數規則
`${count} item${count !== 1 ? 's' : ''}`

// ✅ 正確：使用正式 i18n 庫
t('items', { count }) // 處理複雜複數規則
```

### 錯誤處理

**網路錯誤：**

- 顯示清晰錯誤資訊；
- 提供重試按鈕；
- 解釋發生了什麼；
- 適用時提供離線模式；
- 處理超時。

```jsx
// 帶恢復操作的錯誤狀態
{error && (
  <ErrorMessage>
    <p>Failed to load data. {error.message}</p>
    <button onClick={retry}>Try again</button>
  </ErrorMessage>
)}
```

**表單校驗錯誤：**

- 在欄位附近顯示行內錯誤；
- 資訊清晰、具體；
- 提供修正建議；
- 不無謂阻止提交；
- 出錯時保留使用者輸入。

**API 錯誤：**

- 按狀態碼合理處理：
  - 400：展示校驗錯誤；
  - 401：跳轉登入；
  - 403：展示權限錯誤；
  - 404：展示未找到狀態；
  - 429：展示限流提示；
  - 500：展示通用錯誤並提供支援渠道。

**優雅降級：**

- 核心功能在沒有 JavaScript 時仍可使用；
- 圖片包含 alt 文字；
- 使用漸進增強；
- 為不支援的能力提供回退。

### 邊界情況

**空狀態：**

- 列表無專案；
- 搜尋無結果；
- 沒有通知；
- 沒有可展示資料；
- 提供清晰下一步。

**載入狀態：**

- 首次載入；
- 分頁載入；
- 重新整理；
- 說明正在載入什麼，例如“正在載入你的專案”；
- 長時間操作提供誠即時間預期。

**大資料集：**

- 分頁或虛擬滾動；
- 搜尋和篩選；
- 效能最佳化；
- 不一次載入全部 10,000 條。

**併發操作：**

- 載入期間停用按鈕，避免重複提交；
- 處理競態條件；
- 樂觀更新必須可回滾；
- 提供衝突解決方式。

**被中斷的手勢**（自定義滑塊、拖拽區域、可滾動控制條）：

- 拖動過程中第二個手指或指標落下時，第一個拖動保持原 pointer 或乾淨結束，不能跳到新指標；
- 瀏覽器因滾動取消手勢（`pointercancel`）、捕獲丟失（`lostpointercapture`）、指標在控制元件外釋放，或視窗在拖動中失焦（`blur`）時，清除 dragging 狀態並釋放捕獲；
- 每種中斷髮生後，下一次點選或拖動無需重新整理即可工作。

**權限狀態：**

- 無檢視權限；
- 無編輯權限；
- 只讀模式；
- 清楚解釋原因。

**瀏覽器相容：**

- 為現代能力提供 polyfill；
- 為不支援的 CSS 提供回退；
- 使用特性偵測，不使用瀏覽器偵測；
- 在目標瀏覽器中測試。

### 輸入校驗與清理

**客戶端校驗：**

- 必填欄位；
- 格式校驗（郵箱、電話、URL）；
- 長度限制；
- 模式匹配；
- 自定義規則。

**服務端校驗（始終需要）：**

- 絕不只信任客戶端；
- 校驗並清理全部輸入；
- 防止注入攻擊；
- 限流。

**約束處理：**

```html
<!-- 清晰設定約束 -->
<input
  type="text"
  maxlength="100"
  pattern="[A-Za-z0-9]+"
  required
  aria-describedby="username-hint"
/>
<small id="username-hint">
  僅限字母和數字，最多 100 個字元
</small>
```

### 無障礙韌性

**鍵盤導航：**

- 所有功能可透過鍵盤使用；
- Tab 順序合理；
- 彈窗正確管理焦點；
- 長內容提供跳過連結。

**螢幕閱讀器：**

- 使用正確 ARIA 標籤；
- 透過 live region 播報動態變化；
- alt 文字具有描述性；
- 使用語義化 HTML。

**高對比度模式：**

- 在 Windows 高對比度模式中測試；
- 不只依賴顏色；
- 提供其他視覺線索。

### 效能韌性

**慢速連線：**

- 漸進載入圖片；
- 骨架屏；
- 樂觀 UI；
- 適用時提供 Service Worker 離線支援。

**記憶體洩漏：**

- 清理事件監聽；
- 取消訂閱；
- 清除 timer/interval；
- 元件解除安裝時中止未完成請求。

**節流與防抖：**

```javascript
// 搜尋輸入防抖
const debouncedSearch = debounce(handleSearch, 300);

// 滾動事件節流
const throttledScroll = throttle(handleScroll, 100);
```

## 測試策略

**人工測試：**

- 使用超長、超短和空資料；
- 測試不同語言；
- 測試離線；
- 將網路限制為 3G；
- 使用螢幕閱讀器；
- 只使用鍵盤；
- 測試目標範圍內的舊瀏覽器。

**自動測試：**

- 邊界情況單元測試；
- 錯誤場景整合測試；
- 關鍵路徑 E2E；
- 專案測試工具能驅動輸入時，為每個確認修復的手勢加入行為迴歸測試；
- 視覺迴歸；
- 無障礙測試（axe、WAVE）。

**重要：** 加固就是預期意外。真實使用者會做出設計者沒有預料的操作。

**絕不能：**

- 假設輸入永遠完美；
- 忽略國際化；
- 使用“發生錯誤”這類空泛資訊；
- 忘記離線場景；
- 只信任客戶端校驗；
- 為文字使用固定寬度；
- 假設所有語言和英文一樣短；
- 因單個元件出錯而阻塞整個介面。

## 驗證加固結果

使用邊界情況進行完整測試：

- **長文字：** 使用超過 100 個字元的姓名；
- **Emoji：** 在所有文字欄位中輸入 emoji；
- **RTL：** 使用阿拉伯語或希伯來語；
- **CJK：** 使用中文、日文和韓文；
- **網路問題：** 斷網並限制連線速度；
- **大資料集：** 使用 1,000+ 項；
- **併發操作：** 快速點選提交 10 次；
- **中斷手勢：** 拖動中加入第二個手指、跨控制元件滾動、在外部釋放、拖動中切換視窗，然後再次拖動；
- **錯誤：** 強制 API 報錯並測試所有狀態；
- **空資料：** 刪除全部資料並測試空狀態。
