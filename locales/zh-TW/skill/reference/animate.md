## 訪客模式

- **Persuade + Experience：** 動效可以承載語氣。優先編排一個經過設計的焦點序列，而不是讓每個區塊重複揭示。
- **Operate + Read：** 動效服務於回饋、狀態和連續性。日常過渡要快，不要讓使用者等待頁面載入編排。
- **原生平臺（`ios` / `android` / `adaptive`）：** 遵循 [ios.md](ios.md) 或 [android.md](android.md) 的 Motion 部分，包括平臺的“減少動態效果”行為。不要使用下述 Web 工具。

## 找到任務

檢查現有動效語言、互動狀態、目標裝置和效能預算。只在動效能夠完成以下任務時使用：

- 確認一項操作；
- 讓狀態變化或空間關係易於理解；
- 在導航或佈局變化時保持連續性；
- 在有意義的時刻引導注意力；
- 體現所選視覺世界。

只有無法推斷重要約束時才詢問。不要僅僅因為某個靜態區域存在，就給它新增動畫。

## 確立動效主張

實作前先寫一份簡短計劃：

- **焦點時刻：** 唯一值得特別編排的序列或互動（如果存在）。
- **連續性：** 需要解釋的狀態、佈局或導航變化。
- **回饋：** 需要確認的控制元件和結果。
- **預算：** 哪些效果可能昂貴，以及執行頻率。

焦點時刻必須來自目前產品和介面概念。通用的淡入上移、懸停抬升、視差層或滾動揭示不構成動效主張。

## 根據含義選擇材質

transform 和 opacity 是可靠基礎，但不是全部工具。根據轉換所表達的內容選擇屬性：

- **連續性與關係：** 共享元素動效、FLIP 式 transform、檢視轉換或有意的空間移動。
- **焦點與縱深：** 有邊界的模糊、濾鏡、背景效果、光線或陰影變化。
- **揭示與構圖：** 遮罩、裁剪路徑、裁切或受控遮擋。
- **材質與能量：** 當視覺世界和執行時支援時，使用顏色、漸變位置、紋理、扭曲或著色器效果。
- **狀態與回饋：** 使用能讓因果關係清楚無誤的最小變化。

不要為了炫技疊加多種技術。一個強有力的材質概念貫穿焦點序列和安靜的輔助狀態，通常已經足夠。

當列表確實以列表形式出現時，可以對同級專案使用錯峰動畫。限制總延遲，絕不要把滾動經過的每個區塊都重新解釋為錯峰列表。

## 時長與緩動

時長應表達距離和結果的重要性：

| 時長 | 典型用途 |
|---|---|
| 100～150ms | 即時回饋 |
| 150～300ms | 日常狀態變化 |
| 300～500ms | 佈局、浮層或檢視轉換 |
| 500～800ms | 經過有意編排的焦點入場 |

退出應快於進入。自信入場可使用 `cubic-bezier(0.16, 1, 0.3, 1)` 這類自然減速；不要條件反射地使用彈跳或彈性曲線。過長的回饋會讓人感覺延遲。

## 按執行時實作

- 宣告式狀態和有限序列使用 CSS transition 和 keyframes。
- 需要中斷、編排和動態值時，使用 Web Animations API 或專案現有動效庫。
- 當重點是跨狀態連續性時，使用 View Transitions 或共享元素技術。
- 只有滾動關係本身具有含義時才使用滾動驅動動效，並提供可靠回退。
- 現有技術棧能清晰實作的效果，不要為它增加新依賴。

讓內容在預設狀態下可見，避免指令碼失敗時頁面內容消失。不要隨意動畫化 `width`、`height`、`top`、`left` 和 margin 等驅動佈局的屬性；適當使用 FLIP、transform 或 grid 技術。把模糊、濾鏡、陰影、canvas 和著色器限制在隔離區域。僅在確定會執行動畫時應用 `will-change`。在目標視口和裝置上測量，不要假設使用 transform 就一定快。

## 無障礙與控制

尊重自動播放和聲音偏好。任何非必要迴圈在離開視口或隱藏時都必須停止。

每個 Web 動畫都需要一條經過設計的 `prefers-reduced-motion` 路徑。移除或減弱空間移動，同時保留能傳達含義的透明度、顏色和狀態轉換。減少動態效果意味著動畫更少、更溫和，而不是停用全部動效；確認操作的回饋仍應清晰可見。

## 驗證

- 焦點動效屬於所選視覺世界和目前介面。
- 每項輔助動畫都在解釋回饋、狀態或關係。
- 中斷和重複使用時行為正確。
- 桌面、行動版和鍵盤路徑保持可用。
- `prefers-reduced-motion` 路徑能減少運動，同時不抹去有意義的回饋或狀態變化。
- 昂貴效果在目標裝置上保持流暢。
- 移除某項動畫會損失含義或創作個性，而不只是減少裝飾。

動效的存在有充分理由後，交給 `{{command_prefix}}impeccable polish` 完成最終精修。
