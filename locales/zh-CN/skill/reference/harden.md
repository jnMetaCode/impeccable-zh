只能处理完美数据的设计不具备生产可用性。应针对真实用户带来的输入、错误、语言和网络条件加固界面。

中文产品还应读取 [chinese-ux-copy-cn.md](chinese-ux-copy-cn.md)，验证动态中文文案、金额时间、权限和高风险确认状态。

## 评估加固需求

识别弱点和边界情况：

1. **使用极端输入测试：**
   - 超长文字（姓名、描述、标题）
   - 超短文字（空值、单个字符）
   - 特殊字符（emoji、RTL 文字、重音字符）
   - 大数值（百万、十亿）
   - 大量项目（1,000+ 列表项、50+ 选项）
   - 无数据（空状态）

2. **测试错误场景：**
   - 网络故障（离线、慢速、超时）
   - API 错误（400、401、403、404、500）
   - 校验错误
   - 权限错误
   - 限流
   - 并发操作

3. **测试国际化：**
   - 较长翻译文本（德语通常比英语长约 30%）
   - RTL 语言（阿拉伯语、希伯来语）
   - 字符集（中文、日文、韩文、emoji）
   - 日期和时间格式
   - 数字格式（1,000 与 1.000）
   - 货币符号

**关键要求：** 只能处理完美数据的设计不具备生产可用性。必须针对现实情况加固。

## 加固维度

系统性提高韧性。

### 文本溢出与换行

**长文本处理：**

```css
/* 单行省略 */
.truncate {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

/* 多行截断 */
.line-clamp {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

/* 允许换行 */
.wrap {
  word-wrap: break-word;
  overflow-wrap: break-word;
  hyphens: auto;
}
```

**Flex/Grid 溢出：**

```css
/* 允许 flex 项缩小到内容宽度以下 */
.flex-item {
  min-width: 0;
  overflow: hidden;
}

/* 防止 grid 项溢出 */
.grid-item {
  min-width: 0;
  min-height: 0;
}
```

**响应式文字尺寸：**

- 使用 `clamp()` 实现流式字号；
- 设置可读下限：移动端正文 16px，与排版指南一致；只有真正次要的文字才使用 14px。iOS Safari 会强制放大字号小于 16px 的聚焦输入框，从而破坏表单布局；
- 测试 200% 文字缩放；
- 确保容器能随文字扩展。

### 国际化（i18n）

**文本扩张：**

- 为翻译预留 30%～40% 空间；
- 使用能随内容调整的 flexbox/grid；
- 使用较长语言测试；
- 文字容器避免固定宽度。

```jsx
// ❌ 错误：假设英文文字很短
<button className="w-24">Submit</button>

// ✅ 正确：根据内容扩张
<button className="px-4 py-2">Submit</button>
```

**RTL 支持：**

```css
/* 使用逻辑属性 */
margin-inline-start: 1rem; /* 不使用 margin-left */
padding-inline: 1rem; /* 不使用 padding-left/right */
border-inline-end: 1px solid; /* 不使用 border-right */

/* 或使用 dir 属性 */
[dir="rtl"] .arrow { transform: scaleX(-1); }
```

**字符集支持：**

- 所有环节使用 UTF-8；
- 使用中日韩 CJK 字符测试；
- 使用 emoji 测试，它们可能占 2～4 个字节；
- 处理拉丁、西里尔、阿拉伯等不同书写系统。

**日期和时间格式：**

```javascript
// ✅ 使用 Intl API 正确格式化
new Intl.DateTimeFormat('en-US').format(date); // 1/15/2024
new Intl.DateTimeFormat('de-DE').format(date); // 15.1.2024

new Intl.NumberFormat('en-US', {
  style: 'currency',
  currency: 'USD'
}).format(1234.56); // $1,234.56
```

**复数：**

```javascript
// ❌ 错误：假设只存在英文复数规则
`${count} item${count !== 1 ? 's' : ''}`

// ✅ 正确：使用正式 i18n 库
t('items', { count }) // 处理复杂复数规则
```

### 错误处理

**网络错误：**

- 显示清晰错误信息；
- 提供重试按钮；
- 解释发生了什么；
- 适用时提供离线模式；
- 处理超时。

```jsx
// 带恢复操作的错误状态
{error && (
  <ErrorMessage>
    <p>Failed to load data. {error.message}</p>
    <button onClick={retry}>Try again</button>
  </ErrorMessage>
)}
```

**表单校验错误：**

- 在字段附近显示行内错误；
- 信息清晰、具体；
- 提供修正建议；
- 不无谓阻止提交；
- 出错时保留用户输入。

**API 错误：**

- 按状态码合理处理：
  - 400：展示校验错误；
  - 401：跳转登录；
  - 403：展示权限错误；
  - 404：展示未找到状态；
  - 429：展示限流提示；
  - 500：展示通用错误并提供支持渠道。

**优雅降级：**

- 核心功能在没有 JavaScript 时仍可使用；
- 图片包含 alt 文字；
- 使用渐进增强；
- 为不支持的能力提供回退。

### 边界情况

**空状态：**

- 列表无项目；
- 搜索无结果；
- 没有通知；
- 没有可展示数据；
- 提供清晰下一步。

**加载状态：**

- 首次加载；
- 分页加载；
- 刷新；
- 说明正在加载什么，例如“正在加载你的项目”；
- 长时间操作提供诚实时间预期。

**大数据集：**

- 分页或虚拟滚动；
- 搜索和筛选；
- 性能优化；
- 不一次加载全部 10,000 条。

**并发操作：**

- 加载期间禁用按钮，避免重复提交；
- 处理竞态条件；
- 乐观更新必须可回滚；
- 提供冲突解决方式。

**被中断的手势**（自定义滑块、拖拽区域、可滚动控制条）：

- 拖动过程中第二个手指或指针落下时，第一个拖动保持原 pointer 或干净结束，不能跳到新指针；
- 浏览器因滚动取消手势（`pointercancel`）、捕获丢失（`lostpointercapture`）、指针在控件外释放，或窗口在拖动中失焦（`blur`）时，清除 dragging 状态并释放捕获；
- 每种中断发生后，下一次点击或拖动无需刷新即可工作。

**权限状态：**

- 无查看权限；
- 无编辑权限；
- 只读模式；
- 清楚解释原因。

**浏览器兼容：**

- 为现代能力提供 polyfill；
- 为不支持的 CSS 提供回退；
- 使用特性检测，不使用浏览器检测；
- 在目标浏览器中测试。

### 输入校验与清理

**客户端校验：**

- 必填字段；
- 格式校验（邮箱、电话、URL）；
- 长度限制；
- 模式匹配；
- 自定义规则。

**服务端校验（始终需要）：**

- 绝不只信任客户端；
- 校验并清理全部输入；
- 防止注入攻击；
- 限流。

**约束处理：**

```html
<!-- 清晰设置约束 -->
<input
  type="text"
  maxlength="100"
  pattern="[A-Za-z0-9]+"
  required
  aria-describedby="username-hint"
/>
<small id="username-hint">
  仅限字母和数字，最多 100 个字符
</small>
```

### 无障碍韧性

**键盘导航：**

- 所有功能可通过键盘使用；
- Tab 顺序合理；
- 弹窗正确管理焦点；
- 长内容提供跳过链接。

**屏幕阅读器：**

- 使用正确 ARIA 标签；
- 通过 live region 播报动态变化；
- alt 文字具有描述性；
- 使用语义化 HTML。

**高对比度模式：**

- 在 Windows 高对比度模式中测试；
- 不只依赖颜色；
- 提供其他视觉线索。

### 性能韧性

**慢速连接：**

- 渐进加载图片；
- 骨架屏；
- 乐观 UI；
- 适用时提供 Service Worker 离线支持。

**内存泄漏：**

- 清理事件监听；
- 取消订阅；
- 清除 timer/interval；
- 组件卸载时中止未完成请求。

**节流与防抖：**

```javascript
// 搜索输入防抖
const debouncedSearch = debounce(handleSearch, 300);

// 滚动事件节流
const throttledScroll = throttle(handleScroll, 100);
```

## 测试策略

**人工测试：**

- 使用超长、超短和空数据；
- 测试不同语言；
- 测试离线；
- 将网络限制为 3G；
- 使用屏幕阅读器；
- 只使用键盘；
- 测试目标范围内的旧浏览器。

**自动测试：**

- 边界情况单元测试；
- 错误场景集成测试；
- 关键路径 E2E；
- 项目测试工具能驱动输入时，为每个确认修复的手势加入行为回归测试；
- 视觉回归；
- 无障碍测试（axe、WAVE）。

**重要：** 加固就是预期意外。真实用户会做出设计者没有预料的操作。

**绝不能：**

- 假设输入永远完美；
- 忽略国际化；
- 使用“发生错误”这类空泛信息；
- 忘记离线场景；
- 只信任客户端校验；
- 为文字使用固定宽度；
- 假设所有语言和英文一样短；
- 因单个组件出错而阻塞整个界面。
