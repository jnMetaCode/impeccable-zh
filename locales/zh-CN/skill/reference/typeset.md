处理包含中文的界面时，同时读取 [chinese-typeset-cn.md](chinese-typeset-cn.md)，并把其中的 CJK 回退、混排、断行和缩放检查加入本流程。

## 访客模式

- **说服 + 体验：** 展示字体可以承担品牌声音。在构图需要时，使用明确对比和响应式字号。
- **操作 + 阅读：** 稳定、可扫描和合适行长优先。一个精心调整的字体家族和固定角色级别通常已经足够。
- **原生应用：** 遵循 [ios.md](ios.md) 或 [android.md](android.md)，包括平台字号缩放和无障碍行为。

如果更换字体会产生新的产品身份，应进入 [new-work.md](new-work.md) 并更新 DESIGN.md；否则保留已经确认的字体家族，只改善使用方式。

## 两项隔离评估

如果存在并允许使用子 Agent，独立执行以下两项评估；否则按顺序自行完成。不要让检测器结果预先影响设计判断。

1. **排版评估：** 检查代表性页面和样式。下面每个问题都必须用文件、选择器或计算值回答：
   - **权威与适配：** 当前确定了哪些字体、字重和角色？它们是否适合产品和选定视觉体系，还是未经检查的默认值？每个字体家族是否都有必要？
   - **层级：** 标题、正文、标签、元数据和数据角色能否一眼区分？相邻字号或字重是否过于接近，无法承担不同职责？
   - **尺度与一致性：** 是否存在明确的角色级别，还是任意值的集合？同一角色在不同页面与状态中是否一致？
   - **阅读：** 正文是否保持舒适的 45～75 字符行长？行高、段落节奏、对比度和字间距是否针对实际字体、宽度、语言和界面调整？
   - **压力情况：** 长标题、本地化文本扩张、页面缩放、窄容器、缺失字重和字体回退时会发生什么？
   - **交付：** 是否只加载真正使用的字体资源？回退字体指标、加载策略和可变字体设置能否避免不可见文本与明显布局偏移？
2. **机械扫描：** 运行：

```bash
{{scripts_path}}/impeccable detect --json --scope type [target files or dirs]
```

还要检查检测器无法解释的动态或任意字体值。编辑前综合两项评估，并说明各自单独发现了什么。扫描无问题只是底线，不代表排版优秀。

## 建立系统

编辑前明确：

- 界面需要哪些角色；
- 各角色之间需要怎样的对比；
- 阅读行长和信息密度；
- 哪些现有字体与字重具有权威性；
- 性能、本地化和无障碍约束。

使用能够清晰表达层级的最少角色和字体家族。综合使用字号、字重、空间和色调，不要只靠字号承担全部层级。

## 应用

- 正文必须舒适可读并支持缩放。普通网页正文以 1rem / 16px 为下限，除非高密度角色、平台习惯或用户设置提供充分理由。
- 正文行长控制在 45～75ch。根据行长反向调整行高：行越宽，通常越需要更大行距。
- 深色背景上的浅色文字应同时从三个感知维度补偿：略增行高、略增字间距，并在字体需要时增加一级字重。
- 按具体字体、宽度、语言和对比度调整行高，不套用统一比例。
- 同一角色在不同页面和状态中保持一致。
- 数字、表格、代码和标签内容适合时使用对应 OpenType 特性。
- 只加载实际使用的字体和字重。提供指标兼容的回退字体，避免阻塞文本显示。
- 营销展示字体可根据空间响应式变化；高密度产品和阅读界面应保持空间稳定。
- 保留浏览器缩放、用户字体设置、Dynamic Type 和平台文字缩放能力。
- 使用段落间距或首行缩进作为主要段落节奏；同时使用通常会重复标记边界。

不要为了装饰牺牲可理解性；没有只有第二字体才能承担的明确角色时，不要引入新的字体家族。

## 验证

- 主要、次要、正文和元数据角色无需阅读内容就能区分。
- 长文本在相关宽度和语言下仍然舒适。
- 排版属于该产品及其既有视觉体系。
- 字体加载不会造成明显重排或不可见文本。
- 缩放、文字缩放、焦点、对比度和窄视口路径保持可用。
- 最终机械扫描没有无法解释的发现。

每项都必须提供渲染或源码证据，然后重新扫描。不能用简单的“是”代替验证。

层级稳定后，交给 `{{command_prefix}}impeccable polish`。

## 实时模式签名参数

每个变体声明一个粗粒度 `scale` 参数，并围绕 `var(--p-scale, 1)` 编写字号级别。

```json
{"id":"scale","kind":"range","min":0.85,"max":1.3,"step":0.05,"default":1,"label":"Scale"}
```

只有在真实代表系统选择时，最多再增加一个字体组合或字重参数。遵循 [live.md](live.md) 的参数契约。
